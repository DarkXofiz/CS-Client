# CsClient V11.8 menu update

- Dark menu layout inspired by the supplied screenshot: top tabs, left navigation rail, cards, switches and sliders.
- `COUNTER FLAME` is shown at the top-right of the menu.
- FOV circle options: enable/disable, size, thickness and six colours.
- ESP/debug visualisation only shows objects in your own Unity test scene, tagged `Player` or marked with `TestTarget`.
- Menu hotkey: F6 when Unity's legacy input manager is enabled.
- Copy `WetsukiMenu.cs` into your own Unity project's Assets folder and add it to an active GameObject.
- Ensure `AndroidCommandBridge.cs` is present if you use the Android bridge.

This is source code, not a compiled APK, and has not been device-tested. The visual style is adapted from the provided reference; no third-party APK code was extracted and no automated aiming was added.
